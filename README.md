# Temple-Crowd-Management-System
Pravaah is an AI-powered Crowd Management System designed to efficiently monitor, analyze, and manage crowd flow in temples and other high-footfall areas. The system helps authorities reduce congestion, improve safety, and provide a smoother experience for pilgrims through real-time analytics, prediction, and dashboard monitoring.

🌟 Features
👥 Real-time Crowd Monitoring
📊 AI-based Crowd Prediction System
🗺️ Heatmap Visualization
🔐 User Authentication & Login System
🛕 Temple-wise Dashboard Management
📈 Data Analytics & Reporting
⚡ Dynamic Crowd Density Detection
🧠 Machine Learning Integration
💾 MySQL Database Connectivity
🌐 Interactive Frontend Dashboard
